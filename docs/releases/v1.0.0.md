## Capabilities

Slentore V1 provides:

- OpenAI-compatible streaming Chat Completions benchmarking;
- raw, redacted client-side timing evidence and derived TTFT, TPOT, ICL, TTLT,
  E2E, and throughput summaries;
- opt-in evidence-backed true ITL for vLLM without interpolation;
- fixed-concurrency closed-loop and absolute-time open-loop request-rate load;
- warmup, stop-admission, and drain lifecycle evidence;
- deterministic exact token-length workloads through vLLM `/tokenize`;
- run aggregation, request/token throughput, SLO evaluation, and goodput;
- deterministic sequential experiment sweeps;
- empirical client delivery calibration with portable Go runtime evidence;
- ordinary run schema 7, experiment schema 1, and calibration schema 1
  artifacts with JSON/CSV summaries and atomic publication;
- deterministic local fake-server fixtures, CI, and real-vLLM release
  acceptance tooling.

Client calibration lists evidence for explicitly tested points. It neither
measures GPU capacity nor changes safety guardrails or claims untested values
are safe.

## Explicit V1 non-goals

V1 has no GPU deployment automation, GPU telemetry, database/object-store
persistence, automatic optimal-point or knee selection, distributed load
generation, million-request streaming quantile sketch, server-side kernel
timing, or automatic model-quality evaluation. It does not provision cloud
instances, run NVML/`nvidia-smi`, infer a model's capacity, or manage vLLM.

See the [release checklist](../v1-release-checklist.md) for the completed
exact-SHA release process and its evidence boundaries.
