# LLM Serving Performance Lab

A reproducible laboratory for studying LLM serving performance,
deployment strategies, and observability.

## Historical experiments

The original local single-GPU learning series has been preserved at:

experiments/local-single-gpu-v0/

It contains the original benchmark scripts, configurations, raw results,
plots, reports, methodology notes, and RAG experiments.

## Current development

The repository is being evolved into a reproducible LLM serving
performance harness.

The new implementation will be developed incrementally around:

- benchmarking
- deployment
- observability
- reproducible experiment artifacts

See individual pull requests for the evolution of the architecture.
